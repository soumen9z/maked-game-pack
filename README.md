# 作成したウェブページです。
ウェブページ作成を通してHTML、CSS、JavaScriptについて学んでいます。

## ０：まとめページ(index.html)
- 他ページにつながる目次のページです。
## １：数あてゲーム
- ランダムで設定された数字を Hi or Low で特定するゲームです。
- 難易度選択やグラフ表示のための要素をHTMLで配置する方法を学びました。
## ２：カラオケガチャ
- カラオケで歌う曲がないときにランダムで曲を表示してくれるサイトです。（曲のラインナップは製作者の好みに大きく偏っています。）
- リストやチェックボックスを使って、情報の一覧表示や選択画面を作る方法を学びました。
## ３：数字推理バトル
- 自分が心の中で決めた数字を特定される前に相手の数字を当てるゲームをコンピューターとできるサイトです。
- ラジオボタンや数値入力欄を使って、ゲームの設定や入力画面を作る方法を学びました。
## ４：じゃんけんカラークイズ（試作中）
- じゃんけんのルールにのっとったライフゲームでお題の状態にすることを狙うゲームです。
- 画面遷移について学んでいます。
## ５：役満コレクション
- CPUへの作戦を組み立て、三人麻雀の自動対局で12種類の役満を何局で集められるかに挑むゲームです。[ゲームを開く](./yakuman/index.html)
- 役満ごとの開始条件と優先順位を設定できます。条件を満たす候補がなければ、成立可能な未収集の役満を優先順に狙います。収集卓と通常卓があり、鳴き・打牌方針も設定できます。
- 最速進行では打牌間の待ち時間を省きます。未収集の役満がすべて成立不能になった局を、自動で切り上げる設定もあります。
- 役満チャンスの強調をオンにすると、あと1枚で未収集の役満を和了できるときに自動進行が止まり、役満名と待ち牌を確認しながら1手ずつ観戦できます。
- JavaScriptで和了・得点の判定とCPUの打牌を実装し、作戦や最少局数を `localStorage` で保存しています。HTML・CSS・JavaScriptだけで動作します。
- 収集対象の役満と使用する牌は、[Mリーグ競技規則](https://m-league.jp/about/)と[天鳳の三人打ちルール](https://tenhou.net/man/index.html)を参考にしています。
